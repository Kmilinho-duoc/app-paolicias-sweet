# app-paolicias-sweet

Este proyecto trata del desarrollo de una aplicación móvil para la gestión, cotización y reserva de eventos de banquetería para la empresa "Paolicias.Sweet". Este proyecto fue realizado en Android Studio.

# Pantallas

El proyecto utiliza un total de 5 pantallas:

- Login
- Registro
- Catálogo
- Reserva
- Comprobante

# Estructura

El proyecto utiliza la estructura MVVM (Model-View-ViewMode) y cuenta con la utilización de una base de datos SQLite (utilizando en este caso dos entidades: Usuario y Reserva).

# Uso de recursos nativos

Los recursos nativos utilizados para este proyecto son:

- Cámara: Para tomar una foto del comprobante de la transferencia del 50% del evento a reservar.
- Vibración: Para indicar la exitosa realización de la reserva de evento.
